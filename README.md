# Zoo functions

## Descrição Breve
O Zoo Functions é um projeto desenvolvido em JavaScript, focado na criação de funções para manipulação e gestão de dados relacionados a um zoológico. O projeto não possui uma interface interativa, sendo focado apenas na lógica de programação. Durante o desenvolvimento, foi utilizado ESLint para aplicar boas práticas de "clean code" e Jest para realizar testes unitários das funções criadas.

## Como Rodar o Projeto
1. Clone o repositório do projeto:
   ```bash
   git clone https://github.com/Gzuuu/zoo-functions.git
   ```
2. Entre na pasta onde o repositório foi baixado:
   ```bash
   cd zoo-functions-project
   ```
3. Execute as funções diretamente no ambiente Node.js.

4. Para rodar os testes unitários com Jest, use o comando:
   ```bash
   npm test
   ```

## Tecnologias Utilizadas
- **JavaScript**
- **Eslint**
- **Jest**

## Funcionalidades
- Cálculo de preço de entrada para o zoológico baseado na idade do visitante.
- Manipulação de dados sobre animais, como nome, sexo e outras características.
- Implementação de testes unitários para validar as funções do zoológico.

## Principais Aprendizados
- Utilização de lógica de programação para resolver problemas reais.
- Aprimoramento de boas práticas de desenvolvimento com a aplicação do ESLint para garantir um código mais limpo e de fácil manutenção.
- Criação e execução de testes unitários com Jest para garantir a confiabilidade das funções criadas.
